# ADB 手机调试大全

## 基础连接

```bash
adb devices                 # 查看已连接设备
adb usb                     # 切换到 USB 模式
adb tcpip 5555              # 切换到无线模式
adb connect 192.168.10.12:5555   # 无线连接手机（替换为实际 IP）
adb disconnect              # 断开连接
adb kill-server             # 重启 ADB 服务
```

---

## 查看信息

```bash
adb shell getprop ro.product.model    # 手机型号
adb shell wm size                     # 屏幕分辨率
adb shell wm density                  # 屏幕密度
adb shell dumpsys battery             # 电池信息
adb shell cat /proc/cpuinfo           # CPU 信息
```

---

## 文件操作

```bash
adb push 本地文件 /sdcard/            # 传文件到手机
adb pull /sdcard/文件 ./              # 从手机拉文件到电脑
adb shell ls /sdcard                  # 查看手机文件列表
adb shell rm /sdcard/文件             # 删除手机文件
adb shell mkdir /sdcard/文件夹        # 在手机上创建文件夹
```

---

## 安装卸载 APP

```bash
adb install 应用.apk                 # 安装应用
adb uninstall 包名                    # 卸载应用（如 com.example.app）
adb shell pm list packages           # 列出所有已安装应用
adb shell pm list packages -3        # 只列出第三方应用
```

## 控制手机（按键模拟）

| 按键 | 命令 |
|------|------|
| 电源键 | `adb shell input keyevent 26` |
| Home 键 | `adb shell input keyevent 3` |
| 返回键 | `adb shell input keyevent 4` |
| 音量+ | `adb shell input keyevent 24` |
| 音量- | `adb shell input keyevent 25` |
| 拍照键 | `adb shell input keyevent 27` |
| 点亮屏幕 | `adb shell input keyevent 224` |

## 模拟操作

```bash
adb shell input tap 500 1000              # 点击指定坐标 (x y)
adb shell input swipe 300 1000 300 500    # 滑动 (起点x 起点y 终点x 终点y)
adb shell input text "hello"              # 输入文字（仅支持英文）
```

---

## 截图与录屏

```bash
adb shell screencap /sdcard/screen.png   # 截图保存到手机
adb pull /sdcard/screen.png ./           # 拉取截图到电脑

adb shell screenrecord /sdcard/video.mp4 # 录屏（按 Ctrl+C 停止）
```

## 打开 APP

```bash
# 打开 QQ
adb shell am start -n com.tencent.mobileqq/.activity.SplashActivity

# 打开微信
adb shell am start -n com.tencent.mm/.ui.LauncherUI

# 打开相机
adb shell am start -a android.media.action.IMAGE_CAPTURE
```

---

## 强制停止 APP

```bash
adb shell am force-stop com.tencent.mobileqq   # 强制关闭 QQ
```
