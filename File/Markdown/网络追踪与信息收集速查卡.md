## 一、路由追踪（看数据包怎么走）

### Windows

```cmd
tracert -d 8.8.8.8                              # 不解析主机名（更快）
tracert -h 10 8.8.8.8                           # 指定最大跳数（默认30）
tracert -w 1000 8.8.8.8                         # 指定超时时间（毫秒）
tracert -4 8.8.8.8                              # 强制 IPv4
tracert -6 2001:4860:4860::8888                 # 追踪 IPv6 地址
tracert -j 192.168.1.1 8.8.8.8                  # 松散源路由（Loose Source Route）
```

### Linux / macOS

```bash
traceroute -n 8.8.8.8                           # -n 不解析主机名（更快）
traceroute -I 8.8.8.8                           # 使用 ICMP Echo 请求（绕过防火墙）
traceroute -T -p 80 8.8.8.8                     # 使用 TCP SYN 探测（指定端口 80）
traceroute -U -p 53 8.8.8.8                     # 使用 UDP 探测（指定端口 53）
traceroute -m 20 8.8.8.8                        # 指定最大跳数（默认30）
traceroute -w 2 8.8.8.8                         # 指定超时时间（秒）
traceroute -A 8.8.8.8                           # 显示 AS 号（需要支持）
traceroute -e 8.8.8.8                           # 显示 ICMP 扩展头（MPLS 标签）
traceroute -f 5 8.8.8.8                         # 从第 5 跳开始（跳过前面已知跳）
```

### 高级工具

```bash
mtr 8.8.8.8                                     # 实时追踪 + 丢包率统计（Linux/macOS）
mtr -r -c 10 8.8.8.8                            # 报告模式，发 10 个包后输出
mtr -n 8.8.8.8                                  # 不解析主机名
mtr -u 8.8.8.8                                  # 使用 UDP 而不是 ICMP
mtr -P 443 8.8.8.8                              # 指定目标端口
```

### Windows 版 MTR

```cmd
winmtr 8.8.8.8                                   # Windows 下的 MTR（带图形界面）
```

下载：https://winmtr.net/

### 可视化路由追踪

- https://ipip.net/traceroute — 在线可视化路由追踪（全球节点）
- https://ping.pe/traceroute — 从多个节点追踪到目标

### IPv6 路由追踪

```bash
traceroute6 -n 2001:4860:4860::8888              # IPv6 路由追踪
mtr -6 2001:4860:4860::8888                      # MTR 使用 IPv6
```

### 旁路路由探测（隐蔽）

```bash
traceroute -P icmp 8.8.8.8                       # 伪装成 ICMP（不易被拦截）
traceroute -T -p 443 --tcp 8.8.8.8               # 伪装成 HTTPS 流量
```

> **注意**：部分云服务商拦截 ICMP，用 TCP 穿透性更好

## 三、DNS 深度挖掘（域名背后的一切）

### 基础 DNS 查询

**nslookup**（Windows/Linux）

```cmd
nslookup youtube.com                            # 查 A 记录
nslookup -type=MX youtube.com                   # 查邮件服务器
nslookup -type=NS youtube.com                   # 查域名服务器
nslookup -type=TXT youtube.com                  # 查 TXT（SPF/DKIM/DMARC）
nslookup -type=CNAME youtube.com                # 查 CNAME 别名
nslookup -type=SOA youtube.com                  # 查 SOA（权威 DNS）
nslookup -type=AAAA youtube.com                 # 查 IPv6
nslookup -type=ANY youtube.com                  # 查所有记录（不推荐，常被限制）
nslookup -port 5353 8.8.8.8                     # 指定 DNS 端口
```

**dig**（Linux/macOS，更强大）

```bash
dig youtube.com                                  # 标准查询
dig +short youtube.com                           # 只输出 IP
dig +noall +answer youtube.com                   # 只显示答案部分
dig youtube.com A +trace                         # 追踪 DNS 解析全过程（递归路径）
dig -x 8.8.8.8                                   # 反向查询 IP → 域名（PTR 记录）
dig +dnssec youtube.com                          # 查询 DNSSEC 签名
dig +edns=0 youtube.com                          # 使用 EDNS0
dig @8.8.8.8 youtube.com                         # 指定 DNS 服务器（谷歌公共 DNS）
dig @1.1.1.1 youtube.com                         # 指定 Cloudflare DNS
dig @119.29.29.29 youtube.com                    # 指定 DNSPod 公共 DNS（国内）
dig +nsid youtube.com                            # 查询权威 DNS 的 NSID
```

### 批量域名解析

**从文件批量解析**

```bash
while read domain; do dig +short $domain; done < domains.txt
```

**批量解析并输出 CSV**

```bash
echo "Domain,IP" > result.csv
while read domain; do
  ip=$(dig +short $domain | head -1)
  echo "$domain,$ip" >> result.csv
done < domains.txt
```

### Nmap 扫描（工业标准）

```bash
nmap -sS 8.8.8.8                                 # 隐蔽 SYN 扫描（需 root）
nmap -sT 8.8.8.8                                 # TCP 连接扫描
nmap -sU 8.8.8.8                                 # UDP 扫描
nmap -sV -p 80,443 8.8.8.8                       # 服务版本识别
nmap -sC -p 80 8.8.8.8                           # 默认脚本扫描
nmap -O 8.8.8.8                                  # 操作系统指纹识别
nmap -A 8.8.8.8                                  # 全面扫描（OS + 服务 + 脚本 + traceroute）
nmap -p 1-65535 8.8.8.8                          # 全端口扫描（慢但全面）
nmap -p- --min-rate 10000 8.8.8.8                # 快速全端口扫描
nmap -p 80 --script http-headers 8.8.8.8         # 获取 HTTP 响应头
nmap -p 80 --script http-title 8.8.8.8           # 获取网页标题
nmap -p 443 --script ssl-cert 8.8.8.8            # 获取 SSL 证书
nmap -p 443 --script ssl-enum-ciphers 8.8.8.8    # 枚举 TLS 加密套件
nmap -p 22 --script ssh-hostkey 8.8.8.8          # 获取 SSH 主机密钥
nmap -p 3306 --script mysql-info 8.8.8.8         # 获取 MySQL 信息
nmap -p 6379 --script redis-info 8.8.8.8         # 获取 Redis 信息
```

### Masscan（全网级极速扫描）

```bash
masscan -p 80,443 8.8.8.0/24 --rate=1000         # 扫描 /24 网段的 80/443
masscan -p 1-65535 8.8.8.8 --rate=10000          # 全端口高速扫描（小心）
masscan --output-format json -oJ scan.json 8.8.8.0/24 -p80
masscan -p 80,443,22,3389 192.168.1.0/24 --rate=5000 | tee scan.txt
masscan -p 0-65535 8.8.8.8 --rate=1000 --exclude 255.255.255.255
```

## 六、子域名收集（找到所有隐藏资产）

### 被动收集（不直接访问目标）

**Amass**（最全面的子域名收集工具）

```bash
amass enum -d target.com                         # 主动 + 被动
amass enum --passive -d target.com -o subs.txt   # 只做被动
amass enum -d target.com -config config.ini      # 使用 API 配置
amass enum -d target.com -json subs.json         # 输出 JSON
amass intel -whois -d target.com                 # 获取相关域名
```

**Subfinder**（纯被动，速度快）

```bash
subfinder -d target.com -o subs.txt              # 基础用法
subfinder -d target.com -silent                  # 安静模式
subfinder -d target.com -all                     # 使用所有源
subfinder -d target.com -o subs.txt -recursive   # 递归收集
```

### 主动收集（DNS 爆破）

**gobuster**

```bash
gobuster dns -d target.com -w /usr/share/wordlists/dirb/common.txt
gobuster dns -d target.com -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt
gobuster dns -d target.com -w dict.txt -t 50     # 50 线程
```

**dnsrecon**（多种方法）

```bash
dnsrecon -d target.com -t brt                    # 子域名爆破
dnsrecon -d target.com -t srv                    # SRV 记录枚举
dnsrecon -d target.com -t axfr                   # 尝试 DNS 区域传输（信息泄露）
dnsrecon -d target.com -t goo                    # 使用 Google 搜索引擎
```

**dnsx**（新一代 DNS 工具）

```bash
dnsx -d target.com -a -aaaa -cname -mx -ns -txt -ptr -srv -o result.txt
dnsx -d target.com -a -silent                    # 只输出 A 记录
dnsx -d target.com -json -o result.json          # JSON 输出
```

## 十五、自动化信息收集脚本（一键侦察）

### 综合侦察脚本

```bash
#!/bin/bash
# recon.sh - 一键信息收集

TARGET=$1
OUTPUT_DIR="recon_${TARGET}_$(date +%Y%m%d_%H%M%S)"
mkdir -p $OUTPUT_DIR

echo "[+] 开始侦察目标: $TARGET"
echo "[+] 输出目录: $OUTPUT_DIR"

# 1. IP 解析
echo "[1] 解析 IP..."
dig +short $TARGET > $OUTPUT_DIR/ip.txt
IP=$(cat $OUTPUT_DIR/ip.txt | head -1)

# 2. IP 归属
echo "[2] IP 归属查询..."
curl -s "https://ipinfo.io/$IP" | jq . > $OUTPUT_DIR/ipinfo.json

# 3. Whois
echo "[3] Whois 查询..."
whois $TARGET > $OUTPUT_DIR/whois.txt

# 4. DNS 记录
echo "[4] DNS 记录收集..."
dig $TARGET ANY > $OUTPUT_DIR/dns_all.txt

# 5. 子域名收集（被动）
echo "[5] 子域名收集..."
subfinder -d $TARGET -silent > $OUTPUT_DIR/subdomains.txt

# 6. 证书透明度
echo "[6] 证书透明度查询..."
curl -s "https://crt.sh/?q=%25.$TARGET&output=json" | jq -r '.[].name_value' | sort -u >> $OUTPUT_DIR/subdomains.txt

# 7. 端口扫描（快速）
echo "[7] 端口扫描（快速 top 100）..."
nmap -T4 --top-ports 100 $IP -oN $OUTPUT_DIR/ports.txt

# 8. 路由追踪
echo "[8] 路由追踪..."
traceroute -n -m 20 $IP > $OUTPUT_DIR/traceroute.txt

# 9. 网站指纹
echo "[9] Web 指纹识别..."
whatweb $TARGET > $OUTPUT_DIR/whatweb.txt 2>/dev/null

echo "[+] 侦察完成！结果保存在: $OUTPUT_DIR"
cat $OUTPUT_DIR/ip.txt
```

### 使用方法

```bash
chmod +x recon.sh
./recon.sh example.com
```
