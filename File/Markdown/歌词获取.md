# LrcUp 歌词工具指令速查

## 基础命令

```bash
lrcup autosearch --embed --download .
```

**说明**：获取歌词，自动嵌入到音频文件，并额外保存 `.lrc` 文件到当前目录。

---

## 批量嵌入歌词（不同音频格式）

### FLAC 格式
```bash
for %i in (*.lrc) do if %~zi gtr 100 lrcup embed "%i" "%~ni.flac"
```

### FLAC 格式（带成功/失败提示）
```bash
for %i in (*.lrc) do if %~zi gtr 100 lrcup embed "%i" "%~ni.flac" && echo ✓ %i || echo ✗ %i
```

### MP3 格式
```bash
for %i in (*.lrc) do if %~zi gtr 100 lrcup embed "%i" "%~ni.mp3"
```

### WAV 格式
```bash
for %i in (*.lrc) do if %~zi gtr 100 lrcup embed "%i" "%~ni.wav"
```

---

## 命令解析

| 参数 | 说明 |
|------|------|
| `autosearch` | 自动搜索匹配的歌词 |
| `--embed` | 将歌词嵌入到音频文件中 |
| `--download .` | 额外保存 `.lrc` 歌词文件到当前目录 |
| `embed "%i" "%~ni.flac"` | 将 `%i`（歌词文件）嵌入到同名 FLAC 音频中 |
| `if %~zi gtr 100` | 仅处理大于 100 字节的歌词文件（过滤无效/空文件） |
| `&& echo ✓ %i` | 成功时输出 ✓ 及文件名 |
| `|| echo ✗ %i` | 失败时输出 ✗ 及文件名 |
